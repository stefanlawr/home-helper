# Home Helper

A checklist for everything worth moving out of Pokémon Bank before it shuts down, with a countdown to the shutdown. It tracks game challenges, exclusive Pokémon and shinies, in-game trades and gifts, ribbons, and moves that can no longer be learned, and shows overall progress by category and source game.

Progress is saved in the browser's `localStorage`, so it stays on one device and browser. Move details and learner lists come from [PokeAPI](https://pokeapi.co) when a move is expanded, and are cached locally for 30 days.

## Requirements

Node.js `^20.19.0` or `>=22.12.0` (required by Vite). The version used in CI is in `.nvmrc`, so `nvm use` picks it up.

## Scripts

| Command               | What it does                                                     |
| --------------------- | ---------------------------------------------------------------- |
| `npm run dev`         | Start the development server.                                    |
| `npm run build`       | Run all checks, then build the static site into `dist/`.         |
| `npm run preview`     | Serve the built site locally.                                    |
| `npm run check:data`  | Validate the catalog: game codes, unique IDs, trade game labels. |
| `npm run check:logic` | Test filtering, grouping, keys, and data normalization.          |
| `npm run check:api`   | Test the PokeAPI client against a mocked API.                    |

## Data

The catalog is static JSON in `assets/data/`, loaded at runtime and normalized by `src/data/normalize.js`:

| File                   | Contents                                                                                                        |
| ---------------------- | --------------------------------------------------------------------------------------------------------------- |
| `home-challenges.json` | Game catalog and Pokémon HOME challenges.                                                                       |
| `home-exclusives.json` | Bank-era exclusive Pokémon, shinies and removed moves, from the r/PokemonHome Bank Exclusives Masterpost.       |
| `home-ribbons.json`    | Ribbon groups and how they're obtained, from Smogon's Ribbon Master guide.                                      |
| `home-moves.json`      | Move index, generated by `assets/utils/build_home_moves.py` (see [docs/DATA_REFRESH.md](docs/DATA_REFRESH.md)). |
| `home-trades.json`     | In-game trades, gifts, fossils and other obtainables.                                                           |

Checkbox state is keyed by task ID, so changing an item's ID (or, for exclusives, its name) resets its saved progress.

## Deployment

Pushing to `main` or `master` builds the site and deploys it to GitHub Pages (`.github/workflows/deploy.yml`).
